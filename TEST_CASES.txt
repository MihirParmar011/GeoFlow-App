1. TEST ENVIRONMENT & PREREQUISITES
================================================================================
Before starting testing, ensure the following requirements are met:
- Test APK: Build and install the latest release APK or download via Firebase App Distribution.
- Devices: At least TWO physical Android devices or emulators to test real-time dual-user location sharing.
- Internet Connection: Active Wi-Fi or Cellular 4G/5G data connection.
- Location Services: Device GPS/Location enabled with High Accuracy mode.
- Firebase Backend: Active Cloud Firestore instance and Firebase Authentication.

================================================================================
2. TEST DEVICE MATRIX
================================================================================
- Primary Test Device: Android 12 / 13 / 14 / 15 physical smartphone
- Secondary Test Device: Android 10+ smartphone or Android Virtual Device (AVD)
- Screen Densities: HD+, FHD+, QHD+ (various aspect ratios)

3. MODULE 1: APP LAUNCH, PERMISSIONS & INITIALIZATION
================================================================================

[TC-001] First Launch & Splash Initialization
- Precondition: App freshly installed.
- Steps:
  1. Launch the GeoFlow application.
  2. Observe the initial splash and screen rendering.
- Expected Result:
  - App launches without any crash or ANR (Application Not Responding).
  - Main navigation shell loads with bottom bar (Map, Live, Account).
  - Default localization (English) and dark theme load smoothly.

[TC-002] Location Permission Request - Grant While Using App
- Precondition: Fresh install with no granted permissions.
- Steps:
  1. Open the Map or Live screen.
  2. Trigger location access.
  3. When OS permission dialog appears, tap "While using the app" (Precise location).
- Expected Result:
  - App receives location permission.
  - User's vehicle/location marker appears at exact GPS coordinates on map.
  - Map centers on current location.

[TC-003] Location Permission Request - Denied
- Precondition: Fresh install.
- Steps:
  1. Launch app and tap "Don't allow" on OS permission prompt.
  2. Attempt to toggle location sharing or tap "My Location" button.
- Expected Result:
  - App handles permission refusal gracefully without crashing.
  - In-app snackbar/dialog informs user that location permission is required.

[TC-004] Location Permission - Permanently Denied / Settings Redirect
- Precondition: Permission set to "Never allow" in Android settings.
- Steps:
  1. Attempt to enable live location sharing.
- Expected Result:
  - Dialog or snackbar appears with "Settings" action button.
  - Tapping "Settings" redirects user to Android App Settings page.

[TC-005] GPS / Device Location Disabled Handling
- Precondition: Turn OFF device Location (GPS) in Android quick settings toggle.
- Steps:
  1. Launch app or toggle live location sharing.
- Expected Result:
  - "Location Services Disabled" modal dialog appears.
  - Tapping "Enable Location" opens Android Location Settings.
  - Once GPS is enabled and user returns, map automatically resumes location stream.

8. MODULE 6: REAL-TIME DUAL-USER LIVE LOCATION SHARING
================================================================================

[TC-033] Toggle Live Location Sharing ON/OFF (Self)
- Precondition: On Live Location Screen.
- Steps:
  1. Tap the Live Sharing toggle button / vehicle marker.
- Expected Result:
  - State switches between Sharing ON (cyan active pulse) and Sharing OFF.
  - When ON: Coordinates stream to Firestore `live_locations/{userId}` every 3-5s.
  - When OFF: Live streaming pauses and status indicator shows inactive.

[TC-034] Send Live Location Request to Another User
- Precondition:
  - User A logged in as "alex_01" on Device 1.
  - User B logged in as "sam_02" on Device 2.
- Steps:
  1. On Device 1 (User A), navigate to Live tab.
  2. Tap the "Add Friend / Share" button in top-right.
  3. Enter User B's username: "sam_02".
  4. Tap "Send Request".
- Expected Result:
  - Request document is created in Firestore `location_requests` with status 'pending'.
  - Device 1 shows snackbar "Request sent to sam_02!".
  - Sharing automatically activates for User A.

[TC-035] Receive Real-Time Incoming Request Modal (User B)
- Precondition: User A sent request in TC-034.
- Steps:
  1. Observe Device 2 (User B) screen while anywhere in the app.
- Expected Result:
  - Glassmorphic modal dialog pops up in real-time (< 1s latency).
  - Dialog text: "alex_01 wants to share live locations with you in real-time."
  - Two buttons displayed: "Decline" (red outline) and "Accept" (cyan filled).

[TC-036] Accept Location Share Request (User B)
- Precondition: Modal visible on Device 2 from TC-035.
- Steps:
  1. User B taps "Accept".
- Expected Result:
  - Request document status in Firestore updates to 'accepted'.
  - Live sharing automatically activates on Device 2.
  - Device 2 switches to the Live Location screen.
  - Active session established between User A and User B.

[TC-037] Decline Location Share Request (User B)
- Precondition: User A sends a new request to User B.
- Steps:
  1. User B taps "Decline".
- Expected Result:
  - Request document status in Firestore updates to 'rejected'.
  - Dialog dismisses on Device 2.
  - No location sharing session is created.

[TC-038] Dual-User Real-Time Markers on Map
- Precondition: Active sharing session between User A and User B.
- Steps:
  1. View the Live Location screen on both devices.
- Expected Result:
  - Device 1 shows User A's cyan vehicle marker AND User B's purple partner marker.
  - Device 2 shows User B's cyan vehicle marker AND User A's purple partner marker.
  - Partner marker displays partner's username above the pin.

[TC-039] Smooth Position Animation & Interpolation
- Precondition: Dual-user sharing active.
- Steps:
  1. Move Device 1 (walk or simulate GPS movement).
  2. Observe Device 2's screen.
- Expected Result:
  - Partner marker does not teleport abruptly.
  - Smooth animation controller smoothly glides partner marker between coordinates.

[TC-040] Live Telemetry & Distance Calculation
- Precondition: Dual-user sharing active.
- Steps:
  1. Tap on Partner's marker or open Live info panel.
- Expected Result:
  - Bottom sheet displays:
    * Real-time distance between User A and User B (e.g. "350 m" or "4.2 km").
    * GPS Accuracy indicator (e.g. "±5m").
    * Online / Live pulse indicator.
    * "Center" button to fly camera to partner.
    * "Stop Sharing" button.

[TC-041] Auto-Fit Camera to Both Users
- Precondition: Dual-user sharing active.
- Steps:
  1. Initial load or tap "Fit Both" button.
- Expected Result:
  - Camera bounds automatically frame both User A and User B within the viewport.

[TC-042] Partner Goes Offline / Throttled Updates
- Precondition: Active session.
- Steps:
  1. Turn off internet or background Device 1 for > 30 seconds.
  2. Observe Device 2.
- Expected Result:
  - Partner status changes from green "LIVE" to "Offline" or "Last seen X mins ago".

[TC-043] Terminate Active Sharing Session (User A)
- Precondition: Active session between User A and User B.
- Steps:
  1. User A taps partner marker -> taps "Stop Sharing" (or removes from Account tab).
- Expected Result:
  - Session document is removed from Firestore.
  - Partner marker disappears from both devices.
  - Snackbar confirms "Stopped sharing with sam_02".

[TC-044] Connection Quality Indicator (Green / Orange / Red)
- Precondition: Live Location screen open.
- Steps:
  1. Observe top bar status pill under good Wi-Fi, weak signal, and disconnected state.
- Expected Result:
  - Shows Green dot ("Excellent/Live"), Orange dot ("Weak/Slow"), or Red dot ("Disconnected").

[TC-049] Low Memory / Device Rotation / Screen Resize
- Precondition: Foldable device or screen split-screen mode.
- Steps:
  1. Switch to split screen or rotate device.
- Expected Result:
  - Responsive layout adapts cleanly without overflow errors.

[TC-050] Invalid Search or Route Coordinates Edge Cases

11. STEP-BY-STEP DUAL-DEVICE TESTING PROTOCOL (User A & User B)
================================================================================

Follow this exact script to verify full end-to-end functionality:

--- DEVICE 1 (Tester A) ---
Step 1: Install APK on Device 1.
Step 2: Launch App -> Allow Location Permission.
Step 3: Go to Account Tab -> Register as:
        Username: "tester_alpha"
        Email: "alpha@test.com"
        Password: "TestPassword123!"

--- DEVICE 2 (Tester B) ---
Step 4: Install APK on Device 2.
Step 5: Launch App -> Allow Location Permission.
Step 6: Go to Account Tab -> Register as:
        Username: "tester_beta"
        Email: "beta@test.com"
        Password: "TestPassword123!"

--- INITIATE SHARING ---
Step 7: On Device 1 (tester_alpha) -> Go to "Live" tab.
Step 8: Tap the top-right "Add Friend" icon (+).
Step 9: Type username "tester_beta" -> Tap "Send Request".

--- ACCEPT & VERIFY ---
Step 10: On Device 2 (tester_beta), observe the incoming popup dialog.
Step 11: Tap "Accept" on Device 2.
Step 12: On both devices, observe the map:
         - Device 1 shows "tester_alpha" (Cyan) and "tester_beta" (Purple).
         - Device 2 shows "tester_beta" (Cyan) and "tester_alpha" (Purple).
Step 13: Move Device 1 slightly -> Verify Device 2 sees the purple marker move smoothly.
Step 14: Tap the partner marker on Device 1 -> Verify real-time distance is displayed.
Step 15: Tap "Stop Sharing" -> Verify session ends on both devices.
